# Student Record Manager

A beginner-friendly Python project for managing student records using **file handling** and basic **CRUD operations**.

## Features

* Add a new student record
* View all student records
* Search for a student by name
* Update student information
* Delete a student record
* Stores data in a text file

## Technologies Used

* Python
* File Handling
* Functions
* Basic CRUD Operations

## How to Run

1. Make sure Python is installed on your system.
2. Clone this repository:

   ```bash
   git clone <repository-url>
   ```
3. Navigate to the project folder:

   ```bash
   cd <project-folder>
   ```
4. Run the program:

   ```bash
   python main.py
   ```

## Data Storage

Student records are stored in `student.txt` using a simple comma-separated format:

```text
Rahul,20,85
Aman,21,90
Priya,19,88
```

## Project Purpose

This project was created to practice Python file handling, functions, user input, and CRUD operations through a simple command-line application.
