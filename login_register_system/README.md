# Login & Register System

A simple command-line authentication system built with Python and file handling.

## Features

* Register a new user
* Check for duplicate usernames
* Login with username and password
* Change account password
* Delete user account
* Store user data in a text file
* Menu-driven command-line interface

## Technologies Used

* Python
* File Handling
* Functions
* Loops and Conditional Statements
* String Handling

## Data Storage

User information is stored in `users.txt` using a simple comma-separated format:

```text
username,password
rahul,1234
aman,5678
```

## How to Run

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd <project-folder>
```

Run the program:

```bash
python main.py
```
